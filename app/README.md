- Package: `com.pxt.carcontrol`
- versionName: `3.3`
- versionCode: `6`
- Minimum Android: 6.0 (API 23)
- Target/compile SDK: API 34
- APK: `收集车控制台V3.3.apk` (~56.8 KB)

## Usage

1. Install the APK and enable Bluetooth.
2. Pair the HC-02 module in system settings.
3. Open the app, select the device and connect.
4. Use the eight-way joystick/gear bar for driving; tap the mode button for visual servo auto-collection.

The APK is in this directory.
