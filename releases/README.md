# Prebuilt Firmware

[简体中文](README.zh-CN.md) | **English**

`Fusion_OpenCar.hex` is a prebuilt C30D firmware image for quick verification.

Notes:

- Rebuilding from `firmware/` source is the reference.
- Power off and disconnect the OpenMV↔C30D UART cable before flashing; reconnect afterwards.
- C30D boards/motors from different batches may have different parameters. Raise the wheels for the first test.
