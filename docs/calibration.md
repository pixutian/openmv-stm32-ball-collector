# 相机安装与标定

## 1. 安装位置

- OpenMV H7 固定在车体**前端上方**，镜头朝前下方倾斜（约 30°–45°）。
- 视野下沿尽量覆盖车前 20–60 cm 的地面，球在画面下半部出现。
- 镜头不要被车壳/叶片遮挡；避免阳光直射和强反光地面。

## 2. 像素与实际距离

OpenMV 输出的是像素坐标，C30D 只做“对准 + 接近”，不需要精确测距；但阈值要用实际画面标定：

1. 把球放在车前 **30 / 50 / 80 cm**，记录 OpenMV IDE 里 `blob.pixels()` 的数值。
2. 取 50 cm 附近的值作为 `VISION_NEAR_AREA`，30 cm 附近作为 `VISION_STOP_AREA`。
3. 若球在画面里偏左/偏右，确认 `dx = cx - 160` 的符号与控制方向一致。

## 2.5 焦距标定（位置估计用）

1. 把球放在车前 **已知距离 D**（例如 300 mm）。
2. 在 OpenMV IDE 里读该帧的半径 `r`（像素）。
3. 计算：`FOCAL_PX = 2 * r * D / 40`（球直径 40 mm）。
4. 多测 2–3 个距离取平均，写入 `openmv/main_circle_pos.py` 的 `FOCAL_PX`。

> 距离估计对半径很敏感，远近误差会偏大；自动收集只需要“接近/到位”判断，
> 建议以 `area` 阈值为主、`dist_mm` 仅作参考。

## 3. 阈值标定（OpenMV IDE）

1. 连接 OpenMV，运行 `openmv/main.py`。
2. 打开 **帧缓冲区**，看灰度直方图：乒乓球通常在高亮区（>200）。
3. 调整 `openmv/config.py`：
   - `GRAY_THRESHOLD`：先 `(200, 255)`；地板反光多就提高下限
   - `PIXELS_THRESHOLD`：太小会检到反光点，太大会漏远球
   - `MIN_ROUNDNESS`：过滤长条反光，0.5–0.7 之间
4. 用不同颜色/新旧程度的球测试（白球、黄球、脏球），必要时改 LAB 阈值。

## 4. 串口验证

- OpenMV IDE 的串口终端能看到帧发送（可临时 `print` 调试）。
- 也可以用 PC + USB-TTL 接 C30D 的 UART4（3.3V），运行
  `python3 tools/protocol_sim.py COM5 --sweep` 模拟目标，检查车是否跟随。
- 若无硬件，先 `--dry-run` 检查帧格式：

```
python3 tools/protocol_sim.py --dry-run
```

## 5. 常见问题

| 现象 | 可能原因 |
|---|---|
| 车不动 | 未发 `V`；或 `conf=0`；或串口未通 |
| 转向反向 | `dx` 符号或左右轮定义反了，先手动确认 |
| 一冲一停 | 超时太短 / 帧率太低，检查波特率与线长 |
| 只认白球 | 阈值只覆盖高亮白，需按球色调整 |
| 近距离丢失 | 球超出视野下沿，调整相机俯角或提高 `STOP_AREA` |
